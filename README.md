# Chip-8 Emulator
Emulator supporting original Chip-8 and (unfinished) SuperChip 1.1

## What's already supported?
The emulator (probably) has support for the Original Chip-8 functionality, and the ability to toggle quirks that apply to the system.

## To be implemented
- Full SuperChip 1.1 support with it's own quirks
- Automatic detection of ROM metadata from the Chip8 database
- A better menu bar 
- Debugger

# Chip-8 Emulator
Emulator supporting original Chip-8 and (unfinished) SuperChip 1.1

## What's already supported?
The emulator (probably) has support for the Original Chip-8, Superchip 1.1, and modern interpreter Superrchip functionality, and the ability to toggle quirks that apply to the system.

As far as I know all Superchip functionality works but I cant guarantee it really.
For the original chip-8 I have found games that utilize the 0NNN instruction, and no I am not implementing that.

A simple debug has also been implemented
